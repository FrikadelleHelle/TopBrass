The full candidate contains 128 clean-condenser recordings across MIDI keys49–80, two forces and two takes per force. The actual VST matched the expected source prefix in192 key/velocity/take checks, including both sides of the63/64 force boundary. These are source identity checks, not192 realism judgments.

The condenser maps contain no loops or dedicated release mappings. This source can test different sax tone and attacks, but does not supply the natural endings, dedicated short attacks or connected transitions needed for the complete instrument. Its original SFZ velocity curves, group choking, dynamic-microphone blend, EQ, vibrato and synthesized wind noise are not recreated. Engine note-off envelopes and velocity response are disclosed in the audition. Do not promote the candidate based on the PCM checks.

The original installed bank, parameters and saved patch remain unchanged. Reproduce in a new folder with:

```sh
.venv/bin/python scripts/audition_weresax.py \
  --output artifacts/recording-audit/complete-alto-new-run
```

The default input is the installed VST3. `--stage finish` regenerates the listening report and current-tenor phrase for an existing verified candidate. The candidate is sustain-only, uses silent coverage fixtures for other parts/articulations, and retains the original sax-slot GUI label. It is an audition artifact, not a production instrument release.
